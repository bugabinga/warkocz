# Security

## Current status

warkocz is an early-development bootstrap, not a production-ready Git client.
No released version currently carries a production-support claim.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/bugabinga/warkocz/security/advisories/new).
Do not disclose vulnerabilities, credentials, decrypted content, or private repository data in public issues.

Include affected revision, impact, and a minimal synthetic reproduction where possible.
No response-time guarantee is offered.
